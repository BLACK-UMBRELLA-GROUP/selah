# SELAH WORDING — SPEC — CURRENT VERSION V1 (LOCK 11)

Founder, 6 Nov 2026 (clickable, prototype V23): "A · “Selah” — LOCK it" and "A · “Request a Journey” — LOCK it".
Applies to every screen, today's and every later LOCK.

## 1. The app's name
| Where | Rule | Examples |
|---|---|---|
| All text members can see (labels, titles, buttons, toasts, help, empty states, emails/notifications drafted in the app) | **Selah** - capital S, rest lower case | "My Selah" (tab and title), "Invite someone to Selah", "Your Selah, in one place.", "You must be 18 or older to use Selah.", "Scan Selah Code" |
| The wordmark | Unchanged: "Selah’" (LOOK spec V2) | – |
| Not member-visible | Leave as is: log/debug messages, internal IDs and keys (e.g. `SELAH-DEMO-…`), code identifiers, file names, the business name in Black Umbrella documents | – |

## 2. Asking someone to begin
| Place | Words |
|---|---|
| Main button on a profile | **Request a Journey** |
| While waiting for your Shepherd to accept (SHEPHERD_INVITE V4) | **Request later**; bar: "Waiting for <First name> to accept. You can request a Journey once they say yes."; toast "You can request a Journey once <First name> accepts your invite." |
| Lists and headings | "Journey request(s)" as today |
| The Selah pause (LOCK 7) | Unchanged: heading "Pause before you ask.", primary "Send request" |
